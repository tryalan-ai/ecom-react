# Welcome to the sitegen demo

This site was generated from plain Markdown by **sitegen**, a tiny static site
generator that uses nothing but the Python standard library.

Start with the [getting started guide](getting-started.html) or browse the
[installation instructions](guide/installation.html).

## Highlights

- No third-party dependencies
- Front matter, headings, lists, links and fenced code blocks
- Automatic navigation and an index page

> Everything here is generated at build time; the output is plain HTML.
