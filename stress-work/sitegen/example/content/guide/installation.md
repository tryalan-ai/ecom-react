# Installation

sitegen has **no dependencies**. Clone the repository and run it straight from
the source tree:

```bash
cd stress-work
python3 -m sitegen build sitegen/example/content sitegen/example/public
```

There is nothing to install with `pip`.

## Requirements

- Python 3.8 or newer
- That is it

See the [configuration reference](configuration.html) for the available
options, or head back to [getting started](../getting-started.html).
